# Changelog

## [1.0.0] — November 2026

### Added
- Killer build creator with four-slot sheets and role templates
- Survivor builds with chase, stealth, support and generator-pressure presets
- Perk combination testing with exhaustion and cooldown conflict warnings
- Synergy search by effect, role and required partner perk
- Saved loadouts with duplication and version marking
- Build export as plain text and as a compact file
- Auto-backup of the build library before every save
- Native C++ build, 7 MB, no runtime dependencies
