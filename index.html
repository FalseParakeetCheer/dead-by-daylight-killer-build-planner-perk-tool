01 — Build types

Two roles, one archive

Killers and survivors are not planned the same way. The archive keeps separate sheets for both, so a killer draft never mixes its perk tiers with a survivor chase build.

01

Killer build creator

Draft a four-perk killer loadout by role: chase, slowdown, information or a hybrid. The sheet refuses duplicate perks and reports the tier of every teachable.

02

Survivor builds

Chase, stealth, support or generator pressure. Each survivor sheet carries its own loop notes and the exhaustion budget of the perks you picked.

03

Perk combinations

Build a combination from the whole index and read what it costs: exhaustion conflicts, dead slots during a chase, perks that only trigger on unhook.

04

Synergy search

Start from one perk and see the others that feed it. Search by effect, by role or by the perk that has to be carried alongside.

05

Saved builds

Keep as many loadouts as you like, duplicate one for a variant and mark the versions you actually run in game.

06

Export

Copy a build as plain text for a group chat, or keep the file and reopen it later on the same machine.

02 — Synergy map

One perk is a habit. Four are a plan.

Pick a perk and the map redraws around what actually supports it. Dependencies, exhaustion clashes and perks that quietly cancel each other show up before you commit a slot.

03 — Workflow

Draft, compare, keep

The planner mirrors how a build actually gets made: an idea, a test against what you already run, then a note you can find again next week.

01

Pick a side and a role

Killer or survivor, then chase, slowdown, information, stealth or support. The sheet preloads the slots that role usually fills.

02

Fill four slots

Add perks by name. Conflicts and duplicates are flagged in the same row, so a dead build never reaches the archive.

03

Compare against your old build

Put the draft next to a saved loadout. Perk by perk, the sheet says what the swap gains and what it gives up.

04

Save and export

The build lands in your local library with a timestamp. Export it as text when someone asks what you are running.

05 — Questions

Before you open it

Short answers to what usually comes up first: does it touch the game, does it need an account, and where the builds are stored.

Does the planner touch the game or my account?

No. It is a standalone desktop app with its own local library. It does not read game memory, inject files, sign in to an account or send anything over the network.

Do I need the game running?

No. The planner works from the perk index it ships with, so you can draft a build with the game closed or not installed at all.

Is the perk list complete?

It covers the teachable perks available at the time of the release, with role tags and effect notes. Perks added after a chapter release arrive in the next build.

Can I keep killer and survivor builds together?

Yes, in the same library but on separate sheets. The archive filters by role, so a killer loadout never appears when you are drafting for a survivor.

How does the synergy search work?

You start from one perk and the map redraws around the perks that share its triggers, its effect type or its role. Conflicts are shown in a separate row rather than hidden behind a score.

Where is the library stored?

Inside the extracted folder next to the executable, with a timestamped backup before every save. Move the folder and the library moves with it.
